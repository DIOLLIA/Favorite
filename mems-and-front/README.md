## FE with mems and books

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

### Getting Started
First, run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) by default with your browser to see the result.

### Auth
to make it work locally .env.local file with env var AUTH_SECRET in the root of the project
